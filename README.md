# BelajarOnchain

🇮🇩 **Kuis kripto harian berbahasa Indonesia di jaringan Base.**
Jawab 5 soal tiap hari tentang dasar kripto dan keamanan (wallet, seed phrase, cara mengenali scam, gas, L2).
Lulus kuis = dapat **badge digital (NFT soulbound) gratis**, gas ditanggung aplikasi.

🇬🇧 **A daily Indonesian-language crypto quiz on Base.**
Answer 5 questions a day on crypto and security basics. Pass the quiz to claim a **free soulbound NFT badge**, with gas sponsored by the app.

> ⚠️ Edukasi saja, bukan nasihat keuangan. Tidak ada rekomendasi beli koin atau prediksi harga.
> Education only, not financial advice. No token shilling or price predictions.

## Struktur / Structure

| Folder | Isi / Contents |
|---|---|
| `contracts/` | Smart contract badge (Solidity + Foundry) |
| `app/` | Mini app (Next.js) |
| `content/` | Soal kuis per tanggal (JSON) / Daily quiz questions |
| `scripts/` | Generator kuis & Grant Radar |
| `docs/` | Rencana, metrik, catatan / Plan, metrics, notes |
